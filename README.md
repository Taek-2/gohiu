# 홍익대학교 합격 예측 서비스

2025학년도 수능우수자전형 다군 합격 예측 서비스입니다.

## 기능

- 계열별 학과 선택
- 수능 점수 입력 (국어, 수학, 영어, 한국사, 탐구영역)
- 홍익대학교 환산점수 계산
- 합격 가능성 예측

## 기술 스택

- Backend: Python, Flask
- Frontend: HTML, JavaScript, Bootstrap
- 배포: Vercel

## 설치 및 실행

1. 저장소 클론
```bash
git clone [repository-url]
cd gohiu
```

2. 필요한 패키지 설치
```bash
pip install -r requirements.txt
```

3. 개발 서버 실행
```bash
python -m flask run
```
